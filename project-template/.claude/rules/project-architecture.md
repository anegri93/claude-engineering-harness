# Project Architecture Rules

Replace this template with architecture rules that are true for this repository.

Examples of useful project-specific rules:

- API handlers live in a specific directory and delegate business logic to application services.
- Domain modules must not import infrastructure modules.
- Database access goes through the repository boundary already used by the project.
- Cross-module communication uses a specific public interface.
- New environment variables must be validated by the existing configuration module.

Delete examples that do not apply. Do not force a generic architecture onto the project.
